# Street Drive v003.1

スマホ横画面向け3Dドライブゲームの試作 v003.1 です。

v003では **実車寄りのステアリング感覚** を軸に、カメラ切替・エンジン音・原付モード・NPC車両・信号を追加しました。外部3Dモデルや音源は使わず、Three.jsとWeb Audioだけで動く軽量プロトタイプです。


## v003.1 調整内容

- ハンドル／バイクハンドルから指を離したあと、0ポジションへかなり早めに戻るようセルフセンタリングを強化
- 停車中でも戻りが極端に遅くならないよう最低復元速度を設定
- ほぼ中央まで戻ったら微小な残り角を0へスナップし、ふらつきを防止
- バイクの最大前輪舵角を 29° → 34° に拡大
- バイクの高速域の横グリップ上限を強化し、速度を上げたままでも以前より旋回しやすく調整
- バイクのリーン表現も少し強め、反応を少し速めに調整

## v003 の主な追加・変更

### 実車寄りステアリング
- 車モードは **900°ロック・トゥ・ロック相当（±450°）**
- 指で何度もハンドルを回せるマルチターン操作
- 手を離した瞬間に中央へ戻らず、速度に応じて自然にセルフセンタリング
- 停車中は戻りが弱く、走行中ほど戻りやすい
- バイシクルモデルで旋回を計算
- 高速域では横G上限を設け、急激にヨーが出すぎないよう調整
- 3D車両の前輪もステア角に連動

### 追加機能
- CAMERA: CHASE / HOOD / COCKPIT の3視点
- SOUND: Web Audioによる簡易エンジン音（ブラウザ制限上、初回タップ後に有効化）
- VEHICLE: CAR / SCOOTER 切替
- NPC車両が街を走行
- 中央交差点に信号を設置し、時間で青・黄・赤が切り替わる
- NPCは中央交差点の赤信号で簡易停止
- NPCとの簡易衝突判定
- ミニマップにNPCを表示
- HUD / 操作UIをv003向けに再調整

## スマホ操作

- CAR: 左下のステアリングを指で回す
- SCOOTER: 左下のハンドルバーを左右へ傾ける
- ACCEL: 加速
- BRAKE: 減速 / 停止
- R / N / D: ギア変更（CARのみ。SCOOTERはD固定）
- CAMERA: 視点切替
- VEHICLE: 車 / 原付切替
- SOUND: エンジン音ON/OFF
- ↻: リセット
- Ⅱ: 一時停止

## PC操作

- W / ↑ : アクセル
- S / ↓ / Space : ブレーキ
- A / ← : 左へ操舵
- D / → : 右へ操舵
- C : カメラ切替
- V : 車 / 原付切替
- M : サウンドON/OFF
- E : D
- N : N
- R : R

## 起動

Node.js 18以上推奨。

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

## Vercel公開

1. このフォルダをGitHubへアップロード
2. Vercelで `Add New Project`
3. 対象リポジトリを選択
4. Framework Preset: `Vite`
5. Deploy
