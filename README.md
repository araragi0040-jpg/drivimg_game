# Street Drive v002

スマホ横画面向けのブラウザ3Dドライブゲーム試作です。v002では、ハンドルを「左右ボタン」ではなく、画面上のステアリングを指で実際に回して操作できる方式へ変更し、HUD全体を刷新しました。

## v002の主な変更

- ハンドルを指で回すドラッグ操作
- ハンドル角度を車両のステアリングへ連動
- 指を離すと自然にセンターへ戻る
- 速度に応じて操舵角が穏やかになる簡易車両モデル
- ハンドル角度表示（L / R / CENTER）
- アクセル・ブレーキの押下状態を視覚化
- ギアUIを縦型レールに刷新
- 速度計をコンパクトなデジタルHUDへ刷新
- ミニマップをスマホ風UIへ刷新
- 上部HUD・一時停止画面・バックミラー枠を刷新
- スマホ横画面で操作部分が重なりにくいよう再調整

## スマホ操作

- 左下ハンドル: 指で円を描くように回す
- ACCEL: 加速
- BRAKE: 減速 / 停止
- R / N / D: ギア変更
- 右上 ↻: 車両リセット
- 右上 Ⅱ: 一時停止

## PC操作

- W / ↑: アクセル
- S / ↓ / Space: ブレーキ
- A / ←: 左へ操舵
- D / →: 右へ操舵
- E: Dレンジ
- N: ニュートラル
- R: リバース

## 起動

Node.js 18以上推奨。

```bash
npm install
npm run dev
```

## Vercel公開

1. このフォルダをGitHubへアップロード
2. Vercelで `Add New Project`
3. 対象リポジトリを選択
4. Framework Preset: `Vite`
5. Deploy
