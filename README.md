# Street Drive v001

スマホ横画面向けの、ブラウザで遊べる3Dドライブゲームの最初の試作です。

## v001で入っているもの

- 3Dの架空都市
- 車1台
- 三人称追従カメラ
- 後方確認用バックミラー
- アクセル / ブレーキ
- 左右ステアリング
- D / N / R ギア
- 速度表示
- ミニマップ
- 建物との簡易衝突判定
- PCのWASD / 矢印キー操作
- スマホのタッチ操作
- 車両リセット
- 一時停止
- GitHub + Vercelにそのまま載せやすいVite構成

## 操作

### スマホ
- 左下ハンドル左半分: 左へ曲がる
- 左下ハンドル右半分: 右へ曲がる
- 右下 PEDAL: アクセル
- 右下 BRAKE: ブレーキ
- 右側 R / N / D: ギア
- 左上 ↻: 車両を初期位置に戻す
- 右上 Ⅱ: 一時停止

### PC
- W / ↑: アクセル
- S / ↓ / Space: ブレーキ
- A / ←: 左
- D / →: 右
- E: Dレンジ
- N: ニュートラル
- R: リバース

## 起動

Node.js 18以上推奨。

```bash
npm install
npm run dev
```

表示されたローカルURLをブラウザで開いてください。

## Vercel公開

1. このフォルダをGitHubリポジトリにアップロード
2. Vercelで `Add New Project`
3. 対象GitHubリポジトリを選択
4. Framework Presetは `Vite`
5. Deploy

通常、追加設定は不要です。
